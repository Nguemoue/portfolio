# 🚀 Portfolio v2 - Luc Nguemoue

Portfolio moderne et professionnel développé avec **Next.js 14**, **TailwindCSS**, **Framer Motion** et **Shadcn UI**.

## ✨ Technologies

- **Next.js 14** - App Router avec Server Components
- **TypeScript** - Typage statique
- **TailwindCSS** - Styling moderne et responsive
- **Framer Motion** - Animations fluides et élégantes
- **Shadcn UI** - Composants UI réutilisables
- **Lucide React** - Icônes modernes

## 🎨 Fonctionnalités

### ✅ Sections Complètes
- 🏠 **Hero** - Présentation avec animation de texte (typing effect)
- 👤 **À propos** - Bio, centres d'intérêts, coordonnées
- 🎓 **Parcours** - Formation académique et certifications
- 💼 **Expériences** - Timeline des expériences professionnelles
- 🚀 **Projets** - Grille filtrée de projets (Tous/Entreprise/Personnel)
- 💡 **Compétences** - Compétences techniques avec niveaux animés
- 📧 **Contact** - Formulaire de contact + informations

### 🎯 Design Features
- ✨ Animations Framer Motion sur toutes les sections
- 📱 **100% Responsive** - Desktop, Tablet, Mobile
- 🎨 **Design moderne** - Gradient backgrounds, glassmorphism
- 🌈 **Couleur primaire** - Vert #12d640 (brand color)
- 🖼️ **Images optimisées** - Next.js Image component
- ⚡ **Performance optimale** - SSR + optimisations Next.js

## 🚀 Installation & Lancement

```bash
# Installation des dépendances
npm install

# Développement
npm run dev

# Build production
npm run build
npm start
```

Ouvrez [http://localhost:3000](http://localhost:3000)

## 📁 Structure du Projet

```

```
