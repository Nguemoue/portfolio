## 📞 Si Problème

### Erreur: "Port 3000 already in use"
```bash
npx kill-port 3000
npm run dev
```

### Erreur: "Module not found"
```bash
npm install
npm run dev
```

### Nettoyer le Cache
```bash
rm -rf .next
npm run dev
```
